POST version_3_0/wserv_registrar_vacuna.php Registrar vacuna aplicada ▼
Parametros
cURL
Respuesta
Notas

Content-Type: application/x-www-form-urlencoded — Se envia un unico campo insertvacunado cuyo valor es el JSON serializado como string.

Campo JSONTipoDescripcion
id_flxcore03StringID del registrador (del login)
id_sysvacu04StringID de la vacuna
id_sysofic01StringID del efector
id_sysdesa18StringID del lote
id_sysdesa12StringID del vacunador
id_sysvacu01StringID de la condicion
id_sysvacu02StringID del esquema
id_sysvacu05StringID de la dosis
sysdesa10_nombreStringNombre del beneficiario
sysdesa10_apellidoStringApellido del beneficiario
sysdesa10_dniStringDNI del beneficiario
sysdesa10_sexoStringM o F
sysdesa10_nro_tramiteStringNumero de tramite del DNI
sysdesa10_cadena_dniStringDNI en formato barcode
sysdesa10_edadStringEdad del beneficiario
sysdesa10_fecha_nacimientoStringFecha de nacimiento (dd/mm/yyyy)
vacunador_registradorString0 = vacunador aplica | 1 = registrador aplica
vacunacion_en_terrenoString1 = vacunación en terreno (campaña / salida) | 0 = en establecimiento fijo. Indicado en la pantalla Equipo de trabajo.
sysdesa10_apellido_tutorStringApellido del tutor (menores)
sysdesa10_nombre_tutorStringNombre del tutor (menores)
sysdesa10_dni_tutorStringDNI del tutor (menores)
sysdesa10_sexo_tutorStringSexo del tutor (menores)
fecha_aplicacionStringFecha de aplicacion (dd/mm/yyyy)
curl -X POST "https://dh.formosa.gob.ar/modulos/webservice/php/version_3_0/wserv_registrar_vacuna.php" \
  --data-urlencode 'insertvacunado={
    "id_flxcore03": "123",

    "id_sysvacu02": "3",
    "id_sysvacu05": "4",
    "sysdesa10_nombre": "NOMBRE",
    "sysdesa10_apellido": "APELLIDO",
    "sysdesa10_dni": "12345678",
    "sysdesa10_sexo": "M",
    "sysdesa10_nro_tramite": "123456789",
    "sysdesa10_cadena_dni": "00012345678",
    "sysdesa10_edad": "35",
    "sysdesa10_fecha_nacimiento": "01/01/1990",
    "vacunador_registrador": "0",
    "vacunacion_en_terreno": "1",
    "sysdesa10_apellido_tutor": "",
    "sysdesa10_nombre_tutor": "",
    "sysdesa10_dni_tutor": "",
    "sysdesa10_sexo_tutor": "",
    "fecha_aplicacion": "31/03/2026"
  }'
{
  "codigo_mensaje": "0",
  "mensaje": "Vacuna registrada correctamente"
}
NotaDetalle
JSON en form fieldEl body NO es JSON directo. Es un form con un campo llamado insertvacunado que contiene el JSON como string.
Tutor opcionalSi el beneficiario es mayor, los campos de tutor pueden enviarse vacios.
Formato de fechaUsar dd/mm/yyyy (ej: 31/03/2026).
vacunacion_en_terrenoLa app móvil ya lo envía en el JSON (1/0). Hasta que el PHP lo persista, el valor solo queda en el cliente y en trazas de red.
